Mission dossiers

Four operations, all running. Each one started as a problem I refused to keep solving by hand.

File MC-001Active

Damon

Autonomous sub-class grabber — Savvy Learning

Objective
When another teacher drops a substitute class, it is claimed by whoever sees it first. A human refreshing a page loses that race. Damon doesn't.
Outcome
Damon watches the postings around the clock and claims matching classes in seconds — while I'm teaching, training, or asleep. I review the results; he runs the watch.
Stack
Automation scripts · scheduled watchers · instant alerting · human review queue
File MC-002Active

Reel-Pipeline

Short-form video automation

Objective
Content only works if it ships consistently, and consistency dies the week a human gets busy. The pipeline removes the busywork between an idea and a posted video.
Outcome
A repeatable production line: source material in, finished short-form videos out, on a steady cadence with minimal hands-on time from me.
Stack
Scripted editing workflow · asset templates · batch rendering · scheduled posting
File MC-003Doctrine

AI-Director Playbook

My methodology for directing AI agents

Objective
One prompt is not a workforce. The playbook is the system I built for giving several AI agents real jobs — and trusting the output because it gets verified, not because it sounds confident.
Outcome
Agents with defined roles, written standing orders, and checkpoints I personally clear. Ten thousand teaching sessions taught me the core skill: explain it clearly, check the work, correct fast.
Stack
Multi-agent coordination · verification loops · human-in-the-loop checkpoints · written SOPs
File MC-004Active

Console Remote-Ops Toolkit

Remote operations for game consoles

Objective
Game consoles are computers that hide their controls. This toolkit brings them onto the network where they can be reached, inspected, and operated remotely.
Outcome
Remote control, diagnostics, and automation for console hardware — the same discipline as the rest of the operation: observe first, act precisely, verify everything.
Stack
Remote control tooling · diagnostics · network automation · scripted routines
